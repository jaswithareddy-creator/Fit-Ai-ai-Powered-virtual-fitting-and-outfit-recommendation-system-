# 👗 FitAI

## AI-Powered Virtual Fitting & Outfit Recommendation System

FitAI is a full-stack AI-based fashion application designed
to help users find suitable outfits without trying multiple
clothes physically.

## 🎯 Problem

While shopping offline, customers often need to try multiple
outfits to find the correct size and suitable style.

FitAI aims to reduce this problem using AI.

## 💡 Solution

The user uploads a full-body photo or uses a camera.

The system analyzes the user's body profile and recommends
suitable clothing sizes and outfits based on:

- Body measurements
- Occasion
- Outfit type
- Color preference
- Budget

## 🔄 System Flow

User
↓
Upload Photo / Camera
↓
AI Body Detection
↓
Body Measurement Estimation
↓
Size Recommendation
↓
User Preferences
↓
Outfit Recommendation
↓
Virtual Fitting
